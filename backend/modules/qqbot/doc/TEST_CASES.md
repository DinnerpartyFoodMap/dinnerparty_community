# Bot 文字测试案例库

遵循 [执行协议](../../../doc/TESTING.md)。已有自动化入口 `npm run test:qq-bot`，验证码私信另外跑 `test:qq-verification`；使用假 OneBot 与临时库。

- BOT-C01 开关与身份：配置关闭、缺字段、self_id 与登录账号不匹配；预期 Bot 不以错误身份执行操作、网站仍可用；记录状态可读。已有自动化。
- BOT-C02 命令与 AI 解释（13576c8）：精确本地命令、自然语言 !命令、AI 输出未知动作/越界参数；预期精确命令优先，模型结果只能映射已支持命令并重新校验，不执行任意指令；AI 故障返回受控提示。已有自动化。
- BOT-C03 草稿确认与取消（ce52848）：逐步填写名称/分类/坐标，编辑、取消、超时、跨用户确认；预期未确认不落 Place，取消不能晚到提交，他人不接管草稿；缺必填有明确提示。已有自动化。
- BOT-C04 重放与通知：重复相同提交、通知发送失败再 retry；预期地点只创建一次，通知记录状态按结果推进，失败不删除待重试记录；数据库事务不等待发消息。已有自动化；跨进程重复投递窗口见 BOT-01，不能宣称端到端恰好一次。
- BOT-C05 随机中心与卡片（13576c8）：有账号最近定位、无定位回退、候选不足；卡片发包成功/失败/配置 link/off。预期复用 discovery 的半径与避雷规则，中心选择正确；卡片标题图片共享 places 规则，发包失败降级分享链接。已有自动化。
- BOT-C08 每群随机中心：查看 / 设置 / 清除 `!随机中心`；群成员、群管理员与群主（OneBot `sender.role`）、绑定 QQ 的网站管理员与评论管理员；店名、展会（无展会 / 展会无地点 / 有地点）、坐标（越界、全角逗号）、找不到的关键词；设置后本群与其他群、私聊的 `!随机` 中心；管理接口权限、校验与审计。预期只有群主、群管理员和有 `manage_invites` 的网站管理员能改；失败保留原中心；有群中心的群一律用群中心，其他群和私聊仍是个人定位再默认中心。已有自动化。
- BOT-C06 私信验证码不落群（d285076）：共享群成员查询成功/失败，群临时会话可用/不可用。预期仅确认目标成员后填 group_id 发送私信，不把验证码文本发送群消息；失败返回错误并标记发送失败。已有自动化 test:qq-verification。
- BOT-C07 平台验收（人工环境验证，BOT-01）：在明确授权的测试群与测试账号验证 OneBot 重连、图文展示和 URL 降级；记录 NapCat 版本与平台结果。自动化不向真实群发消息，需另行安排真实平台验证。
