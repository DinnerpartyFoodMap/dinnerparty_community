# 评分与用户向量迁移验收

日期：2026-10-28。本地源码已迁移至独立私有服务；未执行生产数据库升级、实际发布、真实研究导出或训练。

## 交付范围

- 私有服务承接用户画像合成、评分用均值与相似度、信誉和衰减、公开/个人均分、原列表排序。公式、参数和算法版本保持迁移前基线。
- 主后端保留数据库、权限、事务、历史、额度、任务和研究选择。数值结果带输入版本，在事务外计算、复核后整体发布。
- 原四档面板继续即时保存；同分新点击记主动确认，同键重试不重复。确认保留原评分字段、人数、额度及有效画像的刷新期限。
- 提交时间作为首评/改评的体验时间代理；明确选择的创建评分也记录，默认/未知创建评分不推断体验。本人实际介绍贡献关联评价理由。
- 点击、导航、收藏进入类型化证据；收藏镜像去重，跨账号同编号隔离。研究选择须有明确记录；撤回、清空交互和删除进入失效链路。新证据本轮不增加算法影响。

## 原有浏览器套件

加入本轮评分测试后完整浏览器套件为 3/7。原 6 个文件有 2 个通过，以下 4 个失败；补齐 seeds 的未迁移 HEAD 快照也复现同样失败：

- `test_admin_permissions_ui.js`：旧标题“地点修改申请”断言。
- `test_journey_ui.js`：旧同好开关文案选择器。
- `test_place_location_ui.js`：手机添加地点面板外部点击关闭断言。
- `test_user_places_ui.js`：嵌套 span 选择器同时取到包装文字和店名。

这些界面问题独立于本迁移，未据此修改产品。新增评分浏览器测试已单独通过。iOS 本次仅补创建来源字段透传，未在 Windows 上编译 Xcode 工程。

## 合成性能记录

测试不读取真实账号或真实原文。1 倍数据：425 用户、3255 地点、3568 评分，3.94 MB 输入，全信誉批次单次 233 ms；10 倍：39.49 MB 输入、分页后完整结果 3.13 MB、2255 ms。测试进程峰值约 605 MB，包含同进程客户端和服务端。

20 次交互画像请求与 8 个合成异步日记任务并行时，p50/p95 为 15/18 ms。大批次采用分页保持单个响应不超过 1 MiB，全地点个人分保持每位评价者只准备一次向量。以上不是生产容量保证；尚未进行跨机、真实模型图文负载或全链冷/热缓存容量评估。

## 发布边界

主仓库与私有目录是两个 Git 仓库。按用户要求，本次迁移统一落在两个仓库各自的 main，不再保留本次迁移的开发分支；不推送或重置并行的地图/iOS 开发。主仓库不包含私有源码副本或本地算法回退。

发布前需准备两个配对发布物、真实备份并演练回滚，先升级私有服务再升级后端；运行镜像只包含 runtime。研究导出继续默认关闭。具体配置、启动、失效与回滚步骤见 [接入说明](ALGORITHM_SERVICE.md)。
