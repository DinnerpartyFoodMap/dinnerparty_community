# 评分文字测试案例库

遵循 [执行协议](../../../doc/TESTING.md)。除注明外，已有自动化入口为 `npm run test:ratings`（schema / 纯计算 / 声誉批处理 / 评分接口四个文件）。

### RAT-C01 初次迁移与撤回不复活（65ce2d4、ed3b2f9）

前置：旧 Place 数据包含正常分类、避雷分类、无创建者、旧日期 M/D/YYYY。操作：初始化评分表，撤回一个迁移评分，再次 init。预期：合法创建者按标签得到 4 或 1；旧时间转换正确而非初始化当天；不为缺失用户造记录；撤回后重启不补回。

### RAT-C02 分数与每日不同地点配额

前置：固定配额和 UTC 时间，准备多地点。操作：提交字符串、布尔值、小数、0、5；合法评分同一地点多次，撤回再评，换地点到达限额。预期：只接受整数 1–4；同一天同地点只占一个名额；撤回不退款；超限请求无部分写入。

### RAT-C03 北京零点

前置：UTC 15:59:59 与 16:00:00 两侧，用户已用完配额。操作：跨过时间边界读取并评分。预期：按 UTC+8 自然日重置，resets_at 与日标识一致，不依赖运行机器时区。使用测试提供的固定时间入口，不等待真实午夜。

### RAT-C04 综合分和避雷共享规则

前置：不同权重用户，有封禁者，有旧避雷标签但评分 ≥2.5 的地点，有无标签但评分 <2.5 的地点。操作：读取评分摘要、地点列表及搜索/随机候选。预期：公开分为有效权重均值，封禁用户不计入，人数不乘权重；有分以分为准，无分才看标签；2.5 不避雷。跨入口同时跑 test:search、test:random。

### RAT-C05 声誉数学（ed3b2f9）

前置：合成地点完整度、他人收藏、主动评分、采纳申请与固定年龄。操作：调用 calculateReputations，改变输入顺序、本人创建店主动改评、禁用用户、缺少他人证据。预期：贡献封顶、主动证据筛选、三轮同时迭代、留一偏差校正和时间衰减符合专题公式；输入排序不改变输出；不把迁移/创建评分当主动一致度证据。

### RAT-C06 批处理原子性

前置：已有声誉和评分权重，记录 RatingWeightRefresh。操作：成功刷新；模拟中间写入失败后刷新；读取所有记录和成功时间。预期：成功才统一发布，失败保留原快照与旧成功时间；未更新部分不外露。

### RAT-C07 个性化与画像变更

前置：可兼容的不同口味向量、缺画像用户、足够/不足的其他评价者。操作：读 personalized summary，再把某兴趣评分从 ≥3 改到 ≤2。预期：有效时返回口味加权值，证据不足或向量异常按原行为回退；公开分不被个人分覆盖；用户向量更新来源不残留已取消正向兴趣地点。

### RAT-C08 全链时间一致性（待自动化，RAT-01）

用同一个固定时钟驱动配额、迁移、每日声誉刷新和时间衰减，跨日失败后重启再重试。预期：全部日标记和年龄计算可解释，失败不误写刷新时间。现有单元与批处理测试不等于这一组合覆盖。
