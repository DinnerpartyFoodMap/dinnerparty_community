# 观察屋测试案例

格式与状态见 [测试执行协议](../../../doc/TESTING.md)。

- RM-01：`corpus/` 全部语料通过 `validateCorpus`：每句的字数、占位符、禁用词、内心和解释用语、店里不评价店、住民之间的分寸、不用他 / 她 / 它；每个情境正好一种普通做法；问答 1 到 20 各有一题；起床、睡前、睡着三个固定位置和出门的每一步都有情境；每级熟悉度至少 3 段拼桌、2 段隔空剧本，1 到 3 级各有升级剧情；成批比例和每小时可用情境数在范围内。校验器本身也要能拦住典型的坏句子（写心情、感叹号、比喻、他 / 她、剧本里的身体接触和评价店），以及前后矛盾：白天睡着没写完、睡前先睡着、别的句子写几点醒、隔空写晚饭却没标 `when: "dinner"`、升级剧情提吃饭、`meal` 和 `when` 用错剧本类型。已有自动化：`npm run test:rooms`。
- RM-02｜确定性。固定输入重复模拟一天、规划出门或渲染剧本，结果深相等。换日期后日程随种子变化。已自动化（`test_room_simulator.js`、`test_room_scripts.js`、`test_room_outings.js`）。
- RM-03｜时间线。注入普通、探索、辣店、拼桌和隔空时段，检查事件全程有序且互不重叠，第一条是起床，最后进入睡眠。检查外出步骤、条件、时长不足时的省略顺序和剧情占位。已自动化（`test_room_simulator.js`）。
- RM-04｜做法权重。多种子抽取已作答情境，检查答案占比、标签权重、稀有权重、最低权重、近期折扣和标签取消过滤。已自动化（`test_room_simulator.js`）。
- RM-05｜小习惯。为挂钩情境设置小习惯及口头禅，检查小习惯只出现一次、口头禅只来自可替换做法、探索和稀有星标合计遵守上限。已自动化（`test_room_simulator.js`）。
- RM-06｜开放范围。分别以游客、普通住民、管理员和封禁住民访问 `/api/rooms`，核对 `off`、`admin`、`all` 的状态码、登录要求、封禁写限制和私有缓存头。已自动化（`test_room_api.js`）。
- RM-07｜入住和角色卡。核对默认名、空名、字数、标点、链接、联系方式、城市、重复入住，以及互斥标签、数量上限和问答选项校验。验证 `self` 强制关闭互动，第 11 次文本修改返回 429，同日其他字段仍可改，跨北京日重置额度。已自动化（`test_room_api.js`、`test_room_names.js`）。
- RM-08｜当天时间线。固定北京时间读取，核对只返回已开始的事件和 `next_at`。改卡后验证已开始事件保留、后续重排，改城市后验证未开始的外出重选，隔天快照保持生成时的语料版本。已自动化（`test_room_api.js`）。
- RM-09｜打卡。先读一天，再到店打卡。核对当前角色饱食度增加，事件和日程快照保持一致。已自动化（`test_room_api.js`）。
- RM-10｜互访。未登录返回 401。未入住、仅自己可见、关闭小伙伴、主人被封禁、任一方向屏蔽或查看者不在开放范围时，时间线和名场面返回 404。主页 `room` 与披露规则一致，访客响应没有饱食度、角色卡问答和口头禅清单，`day` 和 `moments` 共用按主人数计的限流。已自动化（`test_room_api.js`）。
- RM-11｜排程。每天只领取一次，重启沿用领取记录；开关关闭时无领取；不活跃、当天入住、被封禁、暂停及超出开放范围的屋不排。过滤避雷、任一方低档和近期到访地点，拼桌少于 5 家时改隔空，两份外出同店同时间，隔空在双方清醒窗口内。已自动化（`test_room_p2_smoke.js`）。
- RM-12｜配对。两边须开互动、住民可见且开启同好发现；排除任一方向屏蔽、封禁及昨天已互动的组合；同城优先，一只每天至多一段。已自动化（`test_room_outings.js`、`test_room_p2_smoke.js`）。
- RM-13｜剧本。验证类型、互动前熟悉度、店铺主类和站位。排程排除同一对 30 天及双方各自 7 天内的剧本，耗尽时跳过；固定种子展开星标及升级剧情，起止与预留相同。已自动化（`test_room_scripts.js`、`test_room_p2_smoke.js`）。
- RM-14｜两边一致。两个主人看到同一段的开始、结束、事件顺序和句子逐字相同，前提是昵称均已通过。已自动化（`test_room_p2_smoke.js`）。
- RM-15｜披露与取消。屏蔽、封禁、注销或收窄可见范围后，拼桌用原店原时长展开为独食，隔空和互动名场面隐藏。关闭互动保留已开始的剧情。保存设置和屏蔽接口只取消未开始的剧情。已自动化（`test_room_p2_smoke.js`、`test_room_social.js`）。
- RM-16｜熟悉度。拼桌加 2、隔空加 1，首次升级当天追加新级别的剧情，两边各存一条升级名场面。已自动化（`test_room_p2_smoke.js`）。
- RM-17｜大头照。未拥有角色可用大头照授权取图，同一授权不能取模型文件，过期或无效时返 403；无大头照时字段为 `null`。已自动化（`test_room_texts.js`）。
- RM-18｜文本审核。检查中或明确违规时访客看到角色默认名，主人看到自己填的名。通过后下次读取显示昵称，同名带住民名。调用失败保持检查中，之后可重试。管理员操作清空口头禅、隐藏对外昵称并写审计。已自动化（`test_room_p2_smoke.js`、`test_room_texts.js`）。
- RM-19｜注销。房间、日程、外出、剧情、名场面、熟悉度、自填文字级联删除。另一方的拼桌在读取时降级为独食，隔空隐藏。已自动化（`test_room_p2_smoke.js`）。
- RM-20｜在家吃饭。分别构造空饭点、有外出、有拼桌和空档不足的日程，检查整套餐序与各步窗口，洗碗与饭后活动只接在吃饭之后。一般的隔空剧情不顶掉这一顿、饭不和它重叠；算作晚饭的隔空剧情占位标 `meal`，晚饭时段不再在家吃。已自动化（`test_room_simulator.js`）。
- RM-21｜醒着时的空闲与每天条数。生成 200 个住民日，检查醒着时相邻两条之间的空闲不超过 `maxIdle`（没有可用情境时除外）。不含剧情的条数中位数在 15 到 22 之间。检查一天内做法优先去重。已自动化（`test_room_simulator.js`）。
- RM-22｜单独出门。跨多个日期和标签检查次数分布、饭点权重、候选门槛、探索资格、避雷、口味向量、近期去重及醒着的间隔。已自动化（`test_room_outings.js`）。
- RM-23｜标签推断与角色卡。覆盖口味轴和作息样本的阈值、时间窗口边界、作息互斥、默认小习惯及字段校验。已自动化（`test_room_traits.js`）。
- RM-24｜只读预览。在临时快照上运行样本、剧情、配对、城市和标签统计，对比文件 SHA256，检查输出文件和非法角色卡的非零退出。已自动化（`test_room_preview.js`，没有 `snapshot.sqlite` 时跳过）。
- RM-25｜暂停。在地图设置关闭小伙伴后读取有快照和没有快照的两天，核对 `paused: true`、事件为空、旧快照保留且没有新日程落库。已自动化（`test_room_api.js`、`test_room_social.js`）。
- RM-26｜下架店铺。先生成一次外出并保存星标，再把店设为非公开。核对选店到回家的整组事件及该店名场面均不返回。已自动化（`test_room_api.js`、`test_room_social.js`）。
- RM-28｜拼桌时长。排程出的拼桌时段不短于剧本本身，按店的主类落在单独出门的时长范围内（剧本更长时等于剧本长度，`meal: false` 等于剧本长度）。展开后各条紧挨、最后一条在时段末结束；多出的分钟只加在 `mealBeat` 那条上；`before` 的剧本整段在末尾，主人时间线里前面是自己的点单和吃饭，句子不写“一个人”和已吃完；两边剧本部分逐字相同。已自动化（`test_room_meet_timing.js`）。
- RM-29｜隔空晚饭。`when: "dinner"` 的隔空落在 17:30 至 20:00；两边当天没有出门吃晚饭，晚饭时段没有在家做饭、吃饭、洗碗；当天晚饭时段已有定下的事时不选这类剧本。其他隔空剧情的日子里两边照常吃晚饭。已自动化（`test_room_meet_timing.js`）。
- RM-30｜睡前隔空。`when: "late"` 的隔空开始在两边较早那位睡前一小时内，可以晚于 22:30，结束后还来得及睡前那条。已自动化（`test_room_meet_timing.js`）。
- RM-27｜注销级联。为住民写入 P1 数据及关联的互动、熟悉度和文本记录，再注销账号。核对该住民及其作为任意一方的关联行被删除。已自动化（`test_room_api.js`、`test_room_social.js`）。
