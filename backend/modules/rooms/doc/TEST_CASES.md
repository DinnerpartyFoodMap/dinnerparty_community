# 观察屋测试案例

格式与状态见 [测试执行协议](../../../doc/TESTING.md)。

- RM-01：`corpus/` 全部语料通过 `validateCorpus`：每句的字数、占位符、禁用词、内心和解释用语、店里不评价店、住民之间的分寸、不用他 / 她 / 它；每个情境正好一种普通做法；问答 1 到 20 各有一题；起床、睡前、睡着三个固定位置和出门的每一步都有情境；每级熟悉度至少 3 段拼桌、2 段隔空剧本，1 到 3 级各有升级剧情；成批比例和每小时可用情境数在范围内。校验器本身也要能拦住典型的坏句子（写心情、感叹号、比喻、他 / 她、剧本里的身体接触和评价店）。已有自动化：`npm run test:rooms`。
- RM-02 起（时间线生成、排程、熟悉度、接口、披露规则）：功能尚未实现，待自动化。
