# 观察屋语料写作规范

读的人像看监控一样看小伙伴过日子。每一条都该像随手记下的一行，不像小说，也不像广告。机器能查的禁区在 `../corpus/rules.json`，`npm run test:rooms` 逐句检查；查不出来的靠下面这些规矩和人读。

## 一条的样子

动作 + 一句话（可以没有）+ 细节（可以没有）。动作不超过 20 字，一句话不超过 8 字，细节不超过 14 字。

| 动作 | 一句话 | 细节 |
| --- | --- | --- |
| 小火柴人把菜单翻了三遍 | 「嗯……」 | 最后点了第一眼看到的 |
| 小火柴人到处找耳机 | 「肯定被人拿了」 | 挂在自己脖子上 |
| 柠檬把自己那杯没动过的水推了过去 | | |

## 规矩

1. **只写拍得到、录得到的。** 动作、物件、声音、说出口的话。不写心情、想法、原因，不替读的人下结论。“觉得”“好像”“一脸”“心里”只能出现在说出口的话里。
2. **具体。** 写清是什么东西、几个、第几次：两个蛋、第三杯、翻了三遍、另一只袜子。
3. **允许白忙。** 改主意、找不着、做到一半去干别的，比圆满的结尾像真事。但不是每条都要抖个包袱，平平常常的一条也要有。
4. **细节跟着动作走。** 细节写的是这件事里的一个小地方，不从别处借一句氛围话。
5. **性格靠做法分。** 同一个情境，社恐和自来熟做的事不一样，不靠形容词区分。
6. **不用的词：** 比喻（像……一样、仿佛）、成语和广告词（津津有味、热气腾腾、烟火气、仪式感）、“轻轻地”“默默地”这类叠字加“地”、写心情的词（满足、幸福、治愈）、网络流行语，以及感叹号、波浪号、表情符号。
7. **不用他、她、它。** 小伙伴可能是任何角色，写名字。
8. **不编店的事。** 挂在店里的句子只写小伙伴做了什么。不写好不好吃、贵不贵、排没排队、服务怎么样，也不暗示店的问题（比如“擦了一遍餐具”会被读成餐具不干净）。
9. **不像真实操作。** 小伙伴不打分、不写评价、不收藏、不添加地点、不打卡。
10. **说了时间就要对得上。** 句子里写了“四十分钟”“十点”“两点多”，就给这一条配上对应的 `minutes` 或 `window`；不要写“一下午”这种会被前后事件戳穿的话。
11. **两位住民的小伙伴之间**只写朋友的分寸：不写恋爱和身体接触，不评论外表和身材，不取笑对方。
12. **前后接什么事不固定。** 句子按时段抽，前后接哪条事先不知道。屋里白天“睡着了”要在动作里写完（睡了多久、醒了）；几点醒只由起床那条写；睡前那条后面紧跟睡着，不能先睡着。隔空剧本写正在吃晚饭、问晚饭吃什么时标 `when: "dinner"`，问睡了没、已经刷完牙标 `when: "late"`；升级剧情接在任何剧情后面，不提吃饭。这几条 `npm run test:rooms` 会查。
13. **拼桌是完整的一顿饭。** 拼桌和一个人出门吃一样长，剧本本身短时，多出的时间加在最长那条上。那条写的不是吃饭（比如“三两口吃完了”“在路口又聊了十分钟”）时，用 `meal` 指定，见 [剧本的字段](README.md#剧本的字段)。

## 口头禅和稀有做法

- **`say`**：标在小伙伴自己随口出声的做法上，换成主人填的任何一句口头禅都读得通，比如点完菜的「好了」、发语音时的「我跟你说」。一句话和动作、细节咬在一起的不标，比如嘴硬的「我不困」、找东西时的「钥匙呢」；拟声（「呼——」「刺啦」）和别人说的话也不标。
- **`rare`**：标在少见、有点好笑的小意外上，比如打碎碟子、牙膏挤成洗面奶。抽到时标星，进名场面。普通做法和问答情境里的做法不标，因为它们会天天出现；一个情境最多一种。各个标签的稀有做法尽量分开，免得某种性格的小伙伴名场面特别多。

## 成批读

单条没问题的句子放在一起可能是一个腔调。改完语料，在时间线里整天整天地读（P0 的命令行预览做好之前，可以读本地生成的阅读稿），看三件事：像不像这个小伙伴，有没有出戏的句子，第几天开始觉得重复。
