# 发现文字测试案例库

遵循 [执行协议](../../../doc/TESTING.md)。入口 `npm run test:search`（20 个关键词回归 + 烟测）和 `npm run test:random`。以下前七项已有自动化，规模评估需另做。

### DSC-C01 先联合排序再截断（2566978）

前置：数量超过 limit 的远处名称匹配，另有较旧但中心附近的分类匹配。操作：用有效 center 搜索分类词，设置较小 limit。预期：附近直接分类匹配进入结果，不因 SQL 先截断被遗漏；/search 与 /search/fast 都传递 center 并返回同序数组。

### DSC-C02 精确名称与语义底线

前置：完整名称匹配、附近仅描述含词、远处分类含词，含避雷精确名称。操作：搜索店名与分类词。预期：精确名称最高优先，用户能找到明确要找的避雷店；仅描述匹配不因近距离挤掉直接分类匹配。

### DSC-C03 归一化与拆词

前置：全半角拉丁文字、标点不同名称、词分别出现在名称/分类/描述中。操作：输入全半角、大小写、逗号分词、% 和 _；缺一个词再查。预期：字面规则一致，所有词均需匹配，通配符输入不会扩大召回；连续中文不假定自动分词。

### DSC-C04 避雷语义

前置：低分无标签、高分旧标签、无评分避雷标签及普通地点。操作：普通查询、独立“避雷 火锅”、连续“避雷火锅”。预期：普通查询降序排列避雷但不删除；独立词触发共享规则筛选；连续词按普通字面匹配；2.5 边界与封禁评分排除一致。

### DSC-C05 非法中心与稳定平局

前置：无坐标、非法坐标、合法 0 坐标；相同文字分与创建时间、不同 ID；旧日期。操作：无中心、非法中心、合法中心分别查询并重复。预期：非法位置不得获距离奖励；同输入顺序确定；日期按显式规则解析，不能用宿主时区决定新旧。

### DSC-C06 AI 不可用

前置：禁用模型密钥或本机上游替身返回错误。操作：独立请求关键词和 AI 接口。预期：基础搜索成功；AI 返回 503 unavailable 的既有结构，不捏造推荐；模型返回值需通过本地地点与格式校验。进一步边界入口 test:ai-clients。

### DSC-C07 随机边界与概率

前置：候选分别在 5km 内、边界、外；含无效坐标与避雷；完整池 4 和 5 两组；排除最近两家。操作：固定随机数或统计抽样；有/无兼容画像分别抽取。预期：完整池不足 5 返回空，再排除历史；基础概率和混合公式正确，保留探索概率；缺向量回基础分布，查询失败不能伪装空结果；响应不暴露用户向量。

### DSC-C08 规模与顺路失败边界（待自动化，DSC-01 / DSC-02）

生成可复现的大候选集，记录 P50/P95、候选数和峰值内存，验证排序等价后才讨论索引。顺路另测非法路径、重复点、极短路径、半径边界和避雷过滤；不得把随机推荐距离测试当作顺路覆盖。
