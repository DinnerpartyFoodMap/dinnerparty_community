# 六维刻度、画像解析与地图预加载修正

## 六维偏好 v4

上次 v3 中性先验为 6，另减去本人平均评价信号的一半，导致强偏好难以表达。v4 将先验改为 3，评价习惯校正系数改为 0.25。各轴独立计算，仍使用同一刻度，不按个人最小/最大值强行拉伸，也不引入全站高分先验。

直接评价信号仍为 `x=(score-2.5)/1.5`，每店权重 1；一轴分数为 `0.5 + 0.5 * sum(w * clamp(x - 0.25*userMean, -1, 1)) / (sum(w)+3)`。收藏和其他软行为沿用 v3 的弱信号，免做评价习惯校正；同店仍只保留一份最强证据。向量显示值沿用原始百分位向 0.5 收缩的公式，将先验同步调整为 3。

所有评价都为最高档时，该类 1 / 2 / 15 家店的自动偏好约为 0.594 / 0.650 / 0.813，分别显示“一般 / 喜欢 / 很喜欢”。低值、低于中位数的有效估计仍统一显示“一般”，手填等级不变，不显示来源或推断依据。原创建/历史导入默认评价继续参与。

同一服务器快照的临时副本，取评价历史最多且至少有 3 条评价的 40 位用户，228 个自动轴：

| 检查项 | v3 | v4 |
| --- | ---: | ---: |
| 平均值 | 0.571 | 0.644 |
| 同一用户六维极差的平均值 | 0.277 | 0.369 |
| 一般（<0.6） | 119 | 57 |
| 喜欢（0.6–<0.8） | 109 | 148 |
| 很喜欢（≥0.8） | 0 | 23 |

这只是活跃用户样本的产品刻度诊断，不能证明预测准确率、推荐命中率提高。背景持续更新画像元数据时，三位最大历史用户并发加载仍成功，本机首次约 1.40 秒、缓存后约 0.26 秒；不是线上延迟保证。

## 画像格式

`profile_categories_invalid` 表示分类没有落在训练词表，`profile_values_invalid` 表示属性数值、数组长度或类型不符合契约。改为让模型返回稳定编号：分类 `c000…`、描述属性 `d00…`、评论属性 `r00…`、标记属性 `f00…`。后端按训练契约映射回原始名称、顺序和维度，保持现有 4B 模型包。

资料不足时允许编号属性省略或显式为 null，进入原模型已有的均值填补路径。兼容长度正确的旧数组和规范分类名称；错误长度、越界数值、字符串假分数、未知编号仍拒绝，不补齐错位数组或编造分类。排除的描述属性仍恢复为 null。

表中新增 `extraction_version` 记录提取格式。升级后，旧失败记录在后台按原批次重新尝试，不等待旧格式积累的长退避；已有成功画像继续复用。新失败仍遵守退避。画像/向量请求仍由后台任务完成，不阻塞地图评分接口。

真实 DeepSeek / SiliconFlow 冒烟仅使用三个合成输入（面馆、资料不足、带评论的咖啡简餐），均成功，描述向量均为 1024 维，带评论样本另获得 1024 维评论向量，DS/RV 恢复为 20/28 维。没有上传用户快照内容。此验证不保证所有未来模型响应都合法；异常仍应保留可诊断的错误日志。

## 地图预加载与网页/iOS 显示

原客户端向外预取一圈，评分阈值却按整个预取区域的地点数判断；从密集地图放大后，范围缓存还会阻止补载。另外，卡片把已经收到的本人预测分主动清空，再等详情接口。

现在 `/places/nearby` 同时接受完整预取范围和 `viewMinLng/viewMaxLng/viewMinLat/viewMaxLat` 实际视野。预取标记继续完整返回，只有实际视野内的地点计入 `MAP_EAGER_RATING_LIMIT` 并批量计算评分。实际视野超过阈值时延后，点开单点仍能计算。未传视野参数的旧客户端保持原逻辑。

响应增加 `rating_deferred/rating_eager_limit`，客户端从密集视野缩小到少量点时，即使范围缓存新鲜也会补载。服务器配置仍生效：默认 `100`，合法上限 `500`；`0` 明确关闭所有地图预加载。不要将阈值设为 0 后期待少量点预加载。

网页卡片、评分面板及 iOS 原生卡片使用同一份评分展示状态，立即采用已预加载的综合估计和本人预测；详情请求继续刷新本人投票、额度和完整分布。响应携带 `rating_viewer_id`，只有当前账号匹配才显示预加载本人分；切换账号清理附近缓存。内部首选加成仍不展示。默认/导入评价的地图汇总不丢弃。

## 部署与验证

更新后端并重启，自动新增提取格式列；更新网页，重新构建发布 iOS 客户端。私有 Node 服务和已训练 4B 模型包此次无须修改，不需要 Python。原始快照未修改。若服务端原来设置 `MAP_EAGER_RATING_LIMIT=0`，改为 `100` 并重启才能启用少量点预加载。
