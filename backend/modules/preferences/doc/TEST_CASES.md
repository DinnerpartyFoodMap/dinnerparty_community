# 偏好文字测试案例库

遵循 [执行协议](../../../doc/TESTING.md)。已有入口：`npm run test:preferences`、`test:random`、`test:ratings`。

- PRF-C01 行为归属与去重：两个用户和多个地点，提交合法/非法行为及重复 id；预期不借传入 user_id 写他人画像，未知类型/地点不污染记录，重复曝光按当前规则处理。已有自动化 test:preferences。
- PRF-C02 收藏生命周期：同用户重复收藏、取消收藏，再读取来源；预期 Favorite 幂等，删除后不残留收藏向量来源；API 只返回当前用户收藏。已有自动化 test:preferences。
- PRF-C03 画像版本：准备正确模型与维度、旧算法、错误维度、缺向量、待同步地点；执行画像刷新。预期仅使用兼容数据，报告 source/vector 数量与有效状态，归一化向量可复现；不能把未覆盖来源当已覆盖。已有自动化 test:preferences。
- PRF-C04 评分正向来源：用户评分 3/4 后刷新，再改 1/2 或撤回；预期来源符合算法版本规则，下游不持续使用旧正向信号。已有自动化 test:ratings，消费者同时跑 test:random。
- PRF-C05 推荐读取无额外模型：已有用户与地点向量；用禁止外网替身执行随机个性化。预期本地合成并抽样，模型不调用；画像读取异常按原规则回基础推荐。已有自动化 test:random。
- PRF-C06 地点内容快速连续修改与重试（待自动化，PRF-01）：A 内容请求未完成时改成 B，让 A 后返回再重试。预期旧向量不覆盖新哈希，失败不会把 pending 错标为 ready；需要针对 placeVectorService 的独立故障时序测试。
