# iOS 地图玻璃控件历史验收（v2 阶段）

本清单保留早期验收背景，控件布局与 v2 描述不作为当前协议要求。2026-10-15 当前 JS 地图协议为 `NATIVE_CHROME_PROTOCOL = 6`，以 src/platform/nativeMapChrome.js 和对应 Swift 实现为准；当前验证范围看 [原生工程入口](README.md) 与 [平台案例](../../src/platform/doc/TEST_CASES.md)。本轮只归档文档，不重新构建或修改原生协议。

自动验证：`npm test`、`npm run build:mobile`。这些验证不包含 Swift 编译或真机触摸测试。

历史背景：当时变更需要重新构建 iOS App（桥接协议 v2）。旧二进制与新网页组合会回退到网页工具栏，避免缺失搜索按钮。

## iOS 26+ 真机 / Xcode 模拟器

- 分别点击底栏四项的图标、文字和边缘，确认从左到右为“更多、收藏、添加、搜索”，一次点击只触发一次操作。
- “更多”中能打开“顺路吃”；返回后底栏恢复。未登录点击收藏打开登录，已登录点击收藏打开收藏列表。
- 添加模式可进入和取消；未完成地图初始化、认证核验时相应禁用状态仍有效。
- 右下角头像独立于底栏，没有用户名；登录用户显示真实头像，未登录显示打包的默认头像，加载失败仍有占位头像。头像能打开账号菜单或登录入口。
- 搜索按钮聚焦输入框，键盘正常弹出；输入、清空、提交、选择结果均可用。键盘开合、横竖屏切换后底栏与搜索框没有重叠或错位。
- 在控件外拖动、缩放地图；工具栏和头像之间的空隙仍可操作地图。
- 打开更多、收藏、账号、地点详情、添加表单、确认框后，原生控件收起，弹窗关闭和退出动画完成后恢复。
- 浅色 / 深色主题下检查搜索框、结果列表、菜单、表单和确认框的玻璃表面、对比度与圆角，滚动长内容并使用关闭按钮、下滑关闭。
- VoiceOver 可分别读出四个操作和头像按钮；启用减少透明度后内容保持可读。

## 回退与平台隔离

- iOS 低于 26、关闭原生玻璃或原生握手失败时，网页回退栏仍显示四项及独立头像，全部操作可用。
- 网页端与 Android 保持原有底栏排列和弹窗样式。

原生底栏及头像使用 SwiftUI Liquid Glass；搜索与弹窗保留现有网页内容，通过 iOS 专属样式统一玻璃外观。
