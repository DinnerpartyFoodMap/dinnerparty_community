# 地图界面与 iOS 转场验证（2026-10-28）

环境：Windows、Node.js v24.19.0、系统 Edge。改动留在工作区，未提交、同步到原生包或发布。

## 行为

- 窄屏搜索结果覆盖右侧功能按钮；宽屏筛选紧邻搜索按钮右侧（44px 按钮、8px 间距），顺路吃移入更多。
- 地图列表距离为 500m、1/3/5/10km，默认 3km；中心改成单个下拉按钮，自选与恢复中心保留。
- 主页雷达只显示六个类别名，保留读屏值，为相邻已知轴围成的区域填色。
- 添加地点固定首次有效坐标，打开表单不移动相机；重复点击不替换已选点。
- iOS 收藏、账号和随机美食使用独立玻璃弹窗，淡入淡出，浮动按钮缩小让位；随机抽取的请求、反馈、取消与网页共用。
- 聚合玻璃独立本机开关 `clusterGlass` 默认关闭；协议 v2 裁切可见片段，明暗数字为实色。确认接管后，裁切、非模态筛选、短暂缺帧和切页保留材质；显式关闭、旧壳或桥接明确失效才归还 PNG。
- 设置从右侧进入、向右返回，地图宿主保留；原生侧滑按进度驱动，取消不结束桥接会话。
- 网页返回接收 begin/change/end/cancel，锁定当前页面或顶层浮层，取消保留输入；确认框可用新手势取消，日记内部返回只移动当前内容层。
