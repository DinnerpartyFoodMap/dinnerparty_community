二、高德地图与其他服务方

本站通过高德地图开放平台提供地图、检索、定位及地理服务。网站与移动应用的地图界面使用 JS API；Android 应用获取设备位置使用高德定位 SDK，高德定位失败时（如在境外）改用 Android 系统定位；iOS 应用使用系统定位。高德定位 SDK 只在您使用定位功能时启动，相关信息由高德按其政策处理，本站只接收定位结果。

产品名称
高德地图 JavaScript API 2.0（Web JS SDK，包含 AMap.PlaceSearch、AMap.Geolocation）及高德 Web 服务 API。
提供方
北京高德图强科技有限公司。
用途和场景
地图展示、地点检索、浏览器定位及地理查询。首次使用须在隐私提示中选择同意，之后才启动地图并加载 JS API；拒绝时不启动地图和相关服务。具体查询随功能触发，精确定位还取决于您的操作和设备权限。
信息范围
网络请求的 IP 地址、浏览器及设备运行环境（如 User-Agent、操作系统、屏幕信息）、请求与日志；搜索词、城市、范围、所选地点；定位及地理查询的经纬度和定位结果。浏览器定位可结合浏览器定位与 IP 定位；拒绝精确位置权限后，网络请求仍涉及 IP 及其推断的大致位置。
处理方式
JS API 在终端运行，请求直接发送至高德或经本站代理转发；本站后端还按功能发送查询参数。代理不代表高德不处理信息，范围随功能、终端及权限变化。
隐私政策
《高德地图开放平台隐私权政策》。高德为独立个人信息处理者，您可通过其政策所列渠道行使相关权利，我们会在需要时协助。
产品名称
高德定位 SDK（Android，com.amap.api:location）。
提供方
北京高德图强科技有限公司。
用途和场景
Android 应用的“定位”及启动后的自动定位，用于在地图上显示当前位置及附近、顺路功能。只在您同意本政策、并授予系统位置权限后，于定位时启动单次定位；不申请后台定位，定位完成或超时后即停止。仅授予“大致位置”时只返回大致位置。
信息范围
按高德公布的定位 SDK 说明，定位时可能处理：位置信息（经纬度、精确或大致位置），以及用于计算位置的 GNSS 信息、WiFi 状态与参数、WiFi 列表（SSID、BSSID）、基站信息、信号强度等网络信息；设备品牌与型号、操作系统及版本、运营商、设备标识符（如 OAID）等设备信息；应用名称与版本；IP 地址。实际范围随设备、系统权限及高德 SDK 版本变化，以高德公布的说明为准。
处理方式
SDK 在设备上运行，网络定位请求直接发送至高德服务器；本站只接收 SDK 返回的经纬度、精度及坐标系，按第一部分所述使用。
隐私政策
同上，适用《高德地图开放平台隐私权政策》。

不同意高德处理地图服务所需信息时，请停止使用地图功能。关闭定位权限只限制相应定位能力，不停止地图加载及必要网络请求。本政策页可独立访问。

网页版使用 localStorage、sessionStorage 等本地存储保存登录凭证、主题、地图设置、语言、公告已读状态、界面状态及本机草稿。网站和移动应用还会在本机保存隐私政策版本、同意或拒绝的选择及选择时间，用于记住本机选择；重大政策版本变化或清除该记录后会重新询问。无法保存时，选择仅在本次打开期间生效。移动应用使用系统安全存储保存登录凭证，并按功能保存本机草稿和临时文件。上述存储用于维持功能及保存选择；当前服务未接入独立的广告追踪或第三方流量统计 SDK。

可退出登录、清理浏览器网站数据或清除应用数据。清除本机数据不等于删除服务器账号与内容，也可能导致未上传草稿无法恢复。第三方组件的本地存储同时适用其政策。

四、共享、公开与转让

我们不会出售个人信息。除提供您选择的服务所必要的处理、明确授权或法律法规另有规定外，不向无关第三方提供个人信息。委托服务方应按约定目的和必要范围处理；向独立接收方提供个人信息时，应依法履行告知与单独同意等义务。

主动公开的内容可能被其他用户、搜索引擎或分享接收方访问、复制和传播。地点、评论、评价、聚餐等公开内容，以及确认发布的日记和设为公开的收藏夹，可能包含住民名及您填写的信息。同好发现开启时，参与者可查看相应资料；私人收藏和未发布日记不因此自动公开。

日记私有编辑状态与公开快照分开保存，后续编辑不一定立即更新公开快照；请核对预览，按需重新发布或撤回。撤回会停止本站提供该公开日记的访问，无法保证他人已复制、截图或缓存的内容同步消失。地点投稿及机器人通知可能按业务设置发送至相关群聊。

因法定义务或有权机关依法要求而需要披露时，我们会依法处理。如运营主体变更涉及信息转移，将告知接收方名称和联系方式，并要求其继续履行保护义务；处理目的或方式变化时依法重新取得同意。

五、信息保存与安全

信息按功能保存在您的设备、本站数据库、会话缓存、文件存储及已启用服务方的系统中。以实现所述目的所需的最短时间为保存原则；法定留存、争议处理或安全审计所需数据按相应要求处理：

  • 账号资料、收藏、设置、日记与发布内容在提供相应服务期间保存，可通过已有操作或联系维护者提出更正、删除与注销请求。
  • 最近定位每位用户只保留一条，新位置覆盖旧位置；可通过隐私邮箱申请删除。关闭定位权限不会自动删除此前保存的位置。
  • 登录会话目前有效期为 7 天；重新登录或升级会话会产生新会话记录，可在设置中退出全部设备。
  • 可选交互反馈记录设有 30 天保留窗口，由服务清理机制执行；关闭交互反馈会删除对应交互及推荐决策记录。关闭研究使用后不再将相应记录作为允许研究使用的数据；已导出的去标识数据需通过请求核查处理。
  • 安全日志、必要备份与第三方持有的数据按各自目的、法定期限及政策处理。备份删除可能随备份轮换完成，在此期间应限制进一步处理。

我们通过访问认证、会话校验、权限区分、公私内容分离、日志脱敏及上传图片元数据清理等措施保护信息。图片上传会清理 Exif、XMP、IPTC 等元数据，画面内容仍需您确认。请使用正式 HTTPS 服务地址并妥善保管账号凭证。

发生个人信息安全事件时，将依法补救并按要求告知用户及主管部门。涉及跨境提供个人信息或变更存储安排时，应事先依法说明接收方、信息范围与权利渠道，并完成相应法定程序。

六、您的权利与操作方式

  • 查阅与更正：通过住民设置修改住民名、头像、密码和地图设置，在对应功能管理收藏、日记及有权编辑的内容。需要复制或导出个人信息时，可联系维护者。
  • 关闭同好、反馈与研究：在同好工作区设置中分别关闭；关闭反馈会同时关闭研究并清理对应交互记录，关闭同好后不再参与同好展示。这些开关不自动删除评分、收藏，也不等同于关闭这些业务数据形成的基础口味偏好。需要删除画像、停止相应分析或解释推荐结果时，可通过邮箱提出。
  • 撤回权限与授权：通过系统或浏览器设置关闭位置、照片或相机权限，停止对应后续采集；其他基于同意的处理可联系维护者撤回。撤回不影响此前已依法开展的处理。
  • 删除与撤回公开：使用功能提供的删除、取消收藏、撤回发布及取消公开操作。无法自行删除的记录、最近定位、画像及研究导出关联数据，可通过邮箱申请核查、限制处理或删除。
  • 退出与注销：在住民设置中退出全部设备或注销账号。注销会删除账号记录并清理相关会话与本机账号草稿；不保证所有公开投稿、独立业务记录、分享副本及备份同步删除。需要进一步删除或去除关联身份时，请说明具体内容并联系维护者。
  • 投诉与其他权利：可申请解释处理规则、查阅、复制、补充、更正、删除、限制处理个人信息，并就自动化推荐提出说明或拒绝请求；现有界面无法完成的，可使用邮箱渠道。

我们可能要求必要的身份核验材料以保护账号和他人信息。请勿发送密码或验证码；完成必要核验后，原则上于 15 个工作日内答复。无法满足请求时会说明原因及可行处理方式，法律法规另有规定的从其规定。
