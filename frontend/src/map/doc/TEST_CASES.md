# 地图文字案例

遵循 [执行协议](../../../doc/TESTING.md)。test:map 是纯逻辑测试，AMap 替身浏览器只覆盖特定流程，实际手势与 SDK 用人工环境补充。

### MAP-C01 聚合成员与稳定快照（已有逻辑自动化）

前置：确定坐标/ID 集合，包含重复、无效点和不同缩放。操作：生成引擎结果、快照和转场，反复合并/拆分并中断。预期：按现有去重规则每点只计一次，聚合成员集合不丢不重，图标/名称/数量同步；最终快照稳定。入口 test:map。

### MAP-C02 标记快照、个人叠加与本地修改（已有逻辑自动化；浏览器部分见 MAP-C03）

前置：几份版本与生成时间不同的快照、个人叠加（审核中地点、屏蔽的地点 id）、可控的时钟与网络。操作：本机缓存晚于网络到达；同时刷新；过期刷新；失败后立即重试与强制刷新；本地新增 / 修改 / 删除后先来旧快照再来追上的快照；本地修改过期；只改评价汇总；换账号。预期：旧快照不覆盖新快照，只把网络快照存回本机，同时只有一个请求；失败保留上一份并等待后再试；本地修改在快照追上前保持、追上后丢弃、最多保留 10 分钟；内容不变时返回同一个数组；换账号清空叠加与本地修改。入口 test:map 的 MarkerSnapshotStore / MarkerSnapshotSource；请求头（快照不带 token 与自定义头、叠加层 no-store）见 test:rating；打开卡片补全详情、编辑与保存后标记移动由 MAP-C03 的浏览器回归覆盖。

### MAP-C03 位置编辑与标记更新（已有浏览器自动化，2bc8c5e）

前置：真实 MapView、API、临时 DB，AMap SDK 替身。操作：管理地点 → 修改位置 → 取消、点选、已有标记选择、直接保存/申请审核；窄屏重走。预期：未保存不改服务器，其他字段不丢，保存后标记移动和卡片一致，审核拒绝不移动。入口 frontend test:ui 中位置测试。

### MAP-C04 国际坐标与海外底图（已有逻辑 + 人工验证，d944e8a）

前置：中国区域表边界与境外点，缩放跨 tile 启用阈值，配置存在/缺失两组。操作：坐标转换、区域相交、生成 tile URL；真机境内外缩放与断网。预期：转换一次且区域一致；境外覆盖按规则启停，失败回退高德；不把低精地图当坐标错误。入口 test:map/test:platform；真实 SDK 网络另验。

### MAP-C05 双指、卡片锚点与定位清理（待浏览器/人工，MAP-02）

操作：双指松开后立即拖动，卡片开合/旋转屏幕，定位中离开地图再回来。预期：地图不漂移、不残留手势锁，卡片与目标锚点一致，定位资源释放且不会由旧定位结果重新移动地图。使用实际触摸设备，桌面鼠标替身不能证明双指行为。

### MAP-C07 iOS 原生底图（已有逻辑自动化 + 人工真机）

前置：替身插件（版本、事件、调用记录、可设定的搜索结果）、地图画布、几组地点与网页元素矩形。操作：握手（版本不符、插件不可用、正常）；读写相机与投影；原生相机与点按事件；增删覆盖物与改折线颜色；setFitView / setBounds；切换高德样式；采样触摸区域；标记层：首份快照、缩小合并、平移、放大拆分、点单点与聚合、校准变化；生成样式（默认图、SVG 皮肤图、皮肤聚合图）；坐标：反算、地区划分（深圳 / 香港、横琴 / 澳门、金门、海参崴）、地标判断、手机在大陆 / 香港两种搜索结果、换算与缓存；与 Swift 白名单、版本、动画时长、Xcode 工程对照。预期：失败时 `ready` 拒绝、不留透明底色；相机先更新缓存再按顺序下发、缩放限制 3–20；投影与 `viewport.js` 一致且往返无误差；事件映射为高德同名事件（只平移不发 zoomend，程序移动不发 dragstart）；覆盖物合并下发、移除后清空；标记层沿用网页的转场计划（缩小 mergeInto 同一父聚合，放大 splitFrom 父聚合），相机移动中（mapmove）聚合层级越过滞回边界或视野出缓冲区时立即换节点并播放转场、同一层级内不换、数据变化仍等静止后提交，节点不变不重发、首份与校准重发不播放转场；原生没动时 setCamera 回执纠正乐观缓存，动了则以相机事件为准；校准只在两个地标不矛盾时下结论，香港用 WGS-84 时相机、点按、覆盖物都换算、大陆不受影响；Swift 动画时长与 `MARKER_TIMING` 一致、不用 MapKit 自带聚合；会话结束后的调用与事件丢弃。入口 test:map 的 test-native-map.mjs；动画流畅度、同帧跟随、触摸穿透、样式与真实的苹果搜索结果见 native/doc 的原生底图清单（待真机）。

### MAP-C08 点聚合放大与打开地点的缩放（已有逻辑 + 浏览器自动化，安卓模拟器已验，iOS 待真机）

前置：广州天河一带的公开快照（4194 个地点，13 级时有 12、21 个成员的聚合，17 级时仍被聚合、18 级才单独显示的店，如“希灵三文鱼”）。操作：手指点 13 级的聚合；点按后人为补发一次 mousedown 打断放大；从聚合上开始拖动；地图列表模式把中心换成地图中心后点那家店；坐标重合的两家店、MapKit 到不了目标层级（替身：相机不动 / 补放大没进展）。预期：一次点按放大到展开层级（13→14）并拆开，点按后不再出现 mousedown 与地图 click；被打断时补放大到 14 并拆开；拖动照常平移、不展开聚合；列表点店放大到 18 级、该店单独显示并打开卡片；重合地点保持基准层级；相机放不大时打开成员列表。入口 test:map 的 test-cluster-zoom（standaloneZoom / revealZoom / clusterZoomOutcome；原生底图每次差同样多时 nextClusterZoom 多要差掉的那一截；成员列表的原生面板快照与桥接清洗）、test-native-map（Swift 相机修正：设置前试探并修正请求、试探期间不回传事件）、`npm run test:native-clusters-browser`（聚合上的触摸取消 pointerdown，鼠标与单点不取消）；2026-11-18 在安卓模拟器（debug 包 2.2.5，WebView DevTools 记录相机事件）逐项验证；iOS 原生底图见 native/doc 的原生底图清单。

### MAP-C06 定位上报（已有逻辑自动化）

前置：App 启动时自动定位早于登录状态恢复；同设备换账号；上报接口失败一次。操作：定位 → 恢复登录 → 再次登录同账号 → 重新定位 → 换账号 → 断网定位后恢复。预期：登录后补报一次，同一位置同一凭证不重复，新定位与换账号各报一次，失败后下次登录状态变化时重试，未登录不报。入口 test:map 的 test-location-report；真机 iOS / Android 启动后在 QQ 发 !随机 应显示“距你上次定位的位置”。
