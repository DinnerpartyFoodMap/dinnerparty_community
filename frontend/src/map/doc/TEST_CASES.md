# 地图文字案例

遵循 [执行协议](../../../doc/TESTING.md)。test:map 是纯逻辑测试，AMap 替身浏览器只覆盖特定流程，实际手势与 SDK 用人工环境补充。

### MAP-C01 聚合成员与稳定快照（已有逻辑自动化）

前置：确定坐标/ID 集合，包含重复、无效点和不同缩放。操作：生成引擎结果、快照和转场，反复合并/拆分并中断。预期：按现有去重规则每点只计一次，聚合成员集合不丢不重，图标/名称/数量同步；最终快照稳定。入口 test:map。

### MAP-C02 范围缓存与旧请求（已有逻辑自动化；完整 UI 待补）

前置：多个相交视口和可控请求完成顺序。操作：命中缓存、过期、平移、先发后到。预期：范围覆盖/TTL/淘汰正确，只有有效请求可提交；旧结果不覆盖新视口。入口 test:map 的缓存与 RequestGate，完整 MapView 生命周期见 MAP-02。

### MAP-C03 位置编辑与标记更新（已有浏览器自动化，2bc8c5e）

前置：真实 MapView、API、临时 DB，AMap SDK 替身。操作：管理地点 → 修改位置 → 取消、点选、已有标记选择、直接保存/申请审核；窄屏重走。预期：未保存不改服务器，其他字段不丢，保存后标记移动和卡片一致，审核拒绝不移动。入口 frontend test:ui 中位置测试。

### MAP-C04 国际坐标与海外底图（已有逻辑 + 人工验证，d944e8a）

前置：中国区域表边界与境外点，缩放跨 tile 启用阈值，配置存在/缺失两组。操作：坐标转换、区域相交、生成 tile URL；真机境内外缩放与断网。预期：转换一次且区域一致；境外覆盖按规则启停，失败回退高德；不把低精地图当坐标错误。入口 test:map/test:platform；真实 SDK 网络另验。

### MAP-C05 双指、卡片锚点与定位清理（待浏览器/人工，MAP-02）

操作：双指松开后立即拖动，卡片开合/旋转屏幕，定位中离开地图再回来。预期：地图不漂移、不残留手势锁，卡片与目标锚点一致，定位资源释放且不会由旧定位结果重新移动地图。使用实际触摸设备，桌面鼠标替身不能证明双指行为。
