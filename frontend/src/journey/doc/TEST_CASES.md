# 日记前端文字案例

遵循 [执行协议](../../../doc/TESTING.md)。下列前六项有既有日记浏览器集成覆盖部分或全部步骤，数据库/发布细节同时由后端 test:journeys、test:journey-resolution、test:journey-publication 验证。

### JRN-FC01 自动保存与重载恢复

前置：隔离账号、临时库。操作：手动新建，添加地点、原话、费用并等待同步；reload，从未完成继续。预期：本机/服务端正确恢复，费用 ID 与文本不丢，保存草稿不创建正式日记/地图点。断网保存失败时离开保护有效；网络恢复后重试同步。已有浏览器。

### JRN-FC02 确认丢失与幂等保存

前置：拦截一次草稿 PUT 与 commit，先让服务端完成再模拟客户端未收到。操作：重试相同请求。预期：提示“结果待确认”，不能生成重复日记或地点；再次成功后状态收敛。已有浏览器和后端；不通过改 request_id 绕过冲突。

### JRN-FC03 素材生成与原文标注

操作：新增文字/照片、失败重试、文本模型生成，审阅并添加原文片段。预期：文本模型不接收图片；照片上传状态明确；片段不重叠且可定位原话；生成不等于公开。文字辅助逻辑已有 test:journey-text，完整生成已有浏览器。

### JRN-FC04 位置补丁与用户编辑

前置：同名候选与确认锚点。操作：澄清等待时改备注/费用，返回补丁；重排站点后再应用旧补丁。预期：只合并位置写集，保留用户输入；位置 basis 不匹配拒绝旧补丁。前后端投影已有 test:journey-resolution，页面手动选择在浏览器覆盖。

### JRN-FC05 公开预览、阅读和撤回

操作：私密保存 → 改公开 → 核对将公开内容和关联/创建计划 → 确认 → 从地点进入公开日记 → 撤回。预期：费用/私图不公开；预览不创建地点；公开卡片只读快照；撤回后公开读取失效，私有编辑仍可继续。已有浏览器与后端。

### JRN-FC06 日记入口、页面栈与手机布局

从地图功能栏打开日记，分别进入写日记和日历。检查详情、分享、地图选择往返、嵌套返回与窄屏编辑。预期下层编辑状态保留，返回只关闭最上层，无横向溢出，旧地点日记响应不串卡。真实系统返回与相册另见平台测试。 [平台测试](../../platform/doc/TEST_CASES.md)

### JRN-FC08 AI 提示只出现一次与日常用语

前置：一份 `ai_assisted` 草稿（含模型推测的到访时间和菜品）、一份自己整理的草稿。操作：从入口进入写日记、核对页、公开日记与分享页。预期：入口副标题提一次 AI；核对页只在摘要行前有「AI 整理」小标签，菜品与时间前没有 AI 标签，推测时间显示「时间待确认」并可点「时间没错」；公开日记只在日期行末有「AI 辅助整理」，正文段落下没有「原文摘录 / 作者编辑」；分享贴文旁保留「AI 生成」且导出附注；自己整理的草稿任何页面都不出现 AI 字样；没开 AI 时素材页不提示“未开启”。界面不出现「站」「搜索中心」「未完成」。浏览器测试覆盖入口名、核对页标题、草稿入口和文字标签；AI 标签的出现位置待自动化。

### JRN-FC09 正文、照片与可见性

操作：自己整理一份带描述和三张照片的草稿；核对页把一张照片放到地点，切换另一张为公开，保存为公开。预期：素材页没有可见性；描述出现在「正文」并进入公开预览；照片只在「照片」一处管理，未放到地点的照片在公开时可切换公开；预览说明在地图上新增与关联的数量。浏览器测试覆盖保存与公开流程；照片公开切换待自动化。

### JRN-FC10 iOS 核对页选店与重复确认

操作：iOS App 打开待确认草稿，先编辑一站的店名和时间，再「选择店铺」选候选；另一站按店名搜索地图上已有的店；保存并公开时遇到可能重复的店。预期：编辑表单没有经纬度和地址；选店后回到核对页，之前的修改仍在且该站为已确认；重复确认页逐个选择后可直接公开，提示新增地点数。控制器 smoke 已有（`test:native-panels`）；SwiftUI 渲染与「就在这里」定位待真机。

### JRN-FC07 跨账号与离线持久化（待专项，JRN-F01）

在 A 素材上传/自动保存未完成时换 B，模拟断网冷启动与本机存储空间不足。预期：B 不读取或提交 A 的本机草稿；失败可解释且保留可恢复数据；上传迟到不会绑定另一账号。不得用真实用户草稿作为夹具。
