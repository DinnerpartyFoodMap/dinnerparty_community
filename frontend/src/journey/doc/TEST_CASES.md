# 日记前端文字案例

遵循 [执行协议](../../../doc/TESTING.md)。下列前六项有既有日记浏览器集成覆盖部分或全部步骤，数据库/发布细节同时由后端 test:journeys、test:journey-resolution、test:journey-publication 验证。

### JRN-FC01 自动保存与重载恢复

前置：隔离账号、临时库。操作：手动新建，添加地点、原话、费用并等待同步；reload，从未完成继续。预期：本机/服务端正确恢复，费用 ID 与文本不丢，保存草稿不创建正式日记/地图点。断网保存失败时离开保护有效；网络恢复后重试同步。已有浏览器。

### JRN-FC02 确认丢失与幂等保存

前置：拦截一次草稿 PUT 与 commit，先让服务端完成再模拟客户端未收到。操作：重试相同请求。预期：提示“结果待确认”，不能生成重复日记或地点；再次成功后状态收敛。已有浏览器和后端；不通过改 request_id 绕过冲突。

### JRN-FC03 素材生成与原文标注

操作：新增文字/照片、失败重试、文本模型生成，审阅并添加原文片段。预期：文本模型不接收图片；照片上传状态明确；片段不重叠且可定位原话；生成不等于公开。文字辅助逻辑已有 test:journey-text，完整生成已有浏览器。

### JRN-FC04 位置补丁与用户编辑

前置：同名候选与确认锚点。操作：澄清等待时改备注/费用，返回补丁；重排站点后再应用旧补丁。预期：只合并位置写集，保留用户输入；位置 basis 不匹配拒绝旧补丁。前后端投影已有 test:journey-resolution，页面手动选择在浏览器覆盖。

### JRN-FC05 公开预览、阅读和撤回

操作：私密保存 → 改公开 → 核对将公开内容和关联/创建计划 → 确认 → 从地点进入公开日记 → 撤回。预期：费用/私图不公开；预览不创建地点；公开卡片只读快照；撤回后公开读取失效，私有编辑仍可继续。已有浏览器与后端。

### JRN-FC06 页面栈、同好与手机布局

操作：入口/日历/详情/分享/地图选择往返、嵌套返回、窄屏编辑；关闭同好发现再启用。预期：下层编辑状态保留、返回关闭最上层、无横向溢出、旧地点日记响应不串卡；同意与画像状态一致。已有浏览器；真实系统返回/相册另见 platform。

### JRN-FC07 跨账号与离线持久化（待专项，JRN-F01）

在 A 素材上传/自动保存未完成时换 B，模拟断网冷启动与本机存储空间不足。预期：B 不读取或提交 A 的本机草稿；失败可解释且保留可恢复数据；上传迟到不会绑定另一账号。不得用真实用户草稿作为夹具。
