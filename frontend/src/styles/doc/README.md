# 设计变量

tokens.css 提供间距、圆角、层级等基础变量，由 main.jsx 导入；主题颜色主要由 theme 应用，overlay 与 marker 样式跟随各自模块。当前不全量重写现有行内样式。

维护流程：确定变量所属层 → 修改 token → 核对公共组件和业务页面 → 检查桌面/窄屏/深色/原生安全区。选用 CSS 变量便于跨组件复用，对照把每处数值独立复制更易同步；已有巨量行内样式需分步迁移，不以强行统一数值为目标。

案例（待视觉回归自动化）：STY-C01 主题变化不改变布局尺寸；STY-C02 320px 窄屏和安全区不遮挡操作；STY-C03 reduced motion 与高对比文字可用。位置和日记浏览器测试覆盖部分窄屏，完整设计变量覆盖见 UI-01 的 [清单](../../../doc/HISTORY_AND_TODO.md)。
