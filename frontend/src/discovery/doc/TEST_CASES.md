# 发现交互文字案例

遵循 [执行协议](../../../doc/TESTING.md)。服务端排序和抽样已有后端测试；前端面板级竞态大多待自动化，见 DSC-F01 / DSC-F02。

### DSC-FC01 搜索中心与结果顺序（后端规则已有，前端 UI 待补）

前置：A 中心有附近分类匹配，远方有名称匹配。操作：搜索后移动地图但不再次提交，再手动重新搜索。预期：请求携带提交时中心；旧结果不被前端重新按 ID/名称排序；仅新提交使用新中心。后端 test:search 验证联合排序，不替代这条交互。

### DSC-FC02 连续输入和迟到响应（待自动化）

前置：Q1/Q2 与 POI/本地结果均可独立延迟。操作：提交 Q1、快速提交 Q2，按逆序放行各响应，关闭再打开。预期：Q1 不混入 Q2；取消不报业务错误；空结果、基础结果和 AI 不可用分别展示，不出现重复点击带来的旧选中点。

### DSC-FC03 随机一轮与换账号（待面板自动化，后端 test:random 已有算法测试）

操作：打开记录中心 → 再换一家 → 移图再换 → 按当前中心重新抽取 → 切账号。预期：普通换沿用中心且最多排除最近两家，重定中心/换账号重置本轮；旧请求不得显示到新用户；忙时防重入，候选不足显示已有空状态。

### DSC-FC03b 展会附近随机（浏览器覆盖面板入口，抽取待自动化）

前置：当前展会有地点 / 无地点。操作：打开展会面板 → 展会附近随机美食 → 再换一家 → 按当前地图中心重新抽取；随机面板已打开时再从展会进入。预期：无地点不显示按钮；从展会进入时说明文字和距离以展会为中心，再换一家沿用展会中心；改按地图中心后文字恢复；换中心会重新抽取。`test_exhibition_ui.js` 覆盖按钮与传出的中心。

### DSC-FC04 个性化降级与反馈同意（部分日记浏览器/后端覆盖）

前置：游客、已登录无画像、有效画像、关闭反馈、过期 consent_version。操作：随机和搜索曝光/点击。预期：身份与同意正确决定路径；无画像仍可基础推荐；响应不泄露向量；不能把观察曝光当有已知策略概率的抽样。完整面板矩阵待补。

### DSC-FC05 顺路输入与取消（待自动化）

输入非法链接、空路线、合法路线、解析超时；解析/检索中关闭或改路线。预期：错误可解释，无效输入不启动无限请求，旧路线结果不能覆盖新路线；地点选中与地图高亮对应。不把几何“顺路”描述成实测通行时间。

### DSC-FC06 外部地点必须手动查询（状态单测及浏览器覆盖）

输入、回车、移动地图与刷新标记只查询站内数据；点击“查找未收录地点”才发起外部请求。请求中与结果展示后重复点击不再调用，改词清除旧结果，迟到响应不覆盖新词。失败可重试且保留站内结果，预算关闭不能调用上游；收录外部结果后立即显示站内条目，不重复展示或请求高德。

前端 `test:search` 验证控制器与去重；后端 `tests/maps/test_amap_search_ui.js` 运行实际 React 和路由，覆盖桌面及模拟 iOS 原生输入/提交事件。该模拟不替代 Swift 编译、系统键盘和真机布局验证。
