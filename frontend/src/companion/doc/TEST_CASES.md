# 小伙伴文字案例

遵循 [执行协议](../../../doc/TESTING.md)。规则和状态机由 `npm run test:companion` 覆盖。实际动画可以在预览页看（见 [README](README.md#预览)），下列各项还要在手机上看。

- CMP-C01（test:companion + 预览页；真机待验证，2026-11-20）底栏状态。
  - 首次进地图时小伙伴从上方落下并压扁，之后发呆、游走，走路时朝前进方向转头，不走到右侧按钮底下。
  - 等几轮会爬到右侧按钮组顶上站在中间，待一会儿后蹲下往左跳回地面。
  - 打开地点卡片再关掉，小伙伴从原处继续。
- CMP-C02（test:companion；真机待验证）睡觉与醒来。
  - 白天放着不动 150 秒，就地睡下，头顶冒 z。在按钮上也能睡。
  - 碰一下屏幕或拖动地图时眨眼、甩头、轻蹦一下醒来。iOS 原生底图上只拖地图也算操作。
  - 夜里（23:00–7:00）30 秒没操作就睡。
- CMP-C03（test:companion + 后端 tests/places/test_check_ins.js；真机待验证）饿与饱。
  - 48 小时没打卡（从没打过卡的账号从注册算）时，发呆耷拉着头、左右张望、肚子叫时抖一下，走得慢，不爬按钮。
  - 打卡后回到地图，补一次点头、爱心和蹦两下的庆祝，然后晃着笑；同一次打卡不会重复庆祝。
- CMP-C04（test:companion；真机待验证）与飞行的配合。
  - 小伙伴在按钮顶上或爬到一半时上拉更多功能，它先飞回地面范围上方悬停，不和随抽屉上移的按钮重叠。收起后落回地面。
  - 睡着时上拉更多功能，先醒再飞。
  - 展开搜索时，站在按钮上的小伙伴掉下来。
- CMP-C05（预览页 ?check，2026-11-20 已验证 84 个第三方模型；真机待验证）额外角色。
  - 资源包里的角色没有这些动作组时，用内置动作补上，各状态都会动。
  - 角色自带同名组时用角色自己的。
  - 眼睛参数名不同的模型睡觉时两眼都闭上。
- CMP-C06（真机待验证）打开「减弱动态效果」后小伙伴不走、不爬、不睡；上拉更多功能时淡出，再在上方淡入。
- CMP-C07（真机待验证，2026-11-20）未登录不显示小伙伴。退出登录回到地图，底栏和右侧按钮上都没有小伙伴；重新登录后从上方落下。
- CMP-C08（test:native-panels 覆盖视图模型与白名单；Swift 未编译，真机待验证）iOS 原生小伙伴。
  - 「我的主页」点「小伙伴」：主页不收起，小伙伴页从右侧推入并占满全屏，左边缘右滑途中能看到下面的主页，松手回到主页。
  - 关闭「开启小伙伴」后房间与角色选择消失，地图底栏也不再有小伙伴；再打开恢复。保存失败时开关弹回并提示。
  - 内置角色显示静态预览；有额外角色时可切换，切到额外角色显示图标，地图底栏换成对应角色。
  - 小伙伴页开着时在别处打卡投喂成功，饱食度变化并冒一颗爱心。
- CMP-C09（companion-roam 预览页已验证点击回调；iOS 原生底图与 Swift 真机待验证，2026-11-25）点底栏小伙伴进入小伙伴页。
  - 网页窄屏和安卓：点小伙伴打开小伙伴页，返回回到地图；点它旁边的空地、它的影子仍是地图的拖动和点击。
  - iOS：小伙伴发呆、走动、爬右侧按钮、睡觉时各点一次，都打开原生主页并直接显示小伙伴页；返回先回到主页，再返回回到地图。走动中点它不会点到地图上的店。旧安装包只打开主页。
  - 刚注册的账号回到地图，底栏就有饭桶，点它能进小伙伴页。
- CMP-C10（test:companion 的 test-room-view-model.mjs 覆盖分段、分组、筛选、空状态、日期范围、刷新、名字检查；页面待在浏览器和真机验证）小伙伴页的起名和一天。
  - `ROOMS_AUDIENCE` 关着时小伙伴页和以前一样，没有起名卡片。
  - 没起名：舞台下是起名卡片；起名面板三步走完，名字等于“饭桶”、全是标点、带 QQ 号时不能下一步；选“只有我”时互动开关关闭置灰、说明换成只有自己能看；第 3 步能上一题、跳过、以后再答；填到一半关面板先确认。
  - 起名后：名字和“编辑”、“现在”一行、今天的时间线只到现在；筛选名场面、互动没有内容时显示对应空状态；翻到前一天、再翻回今天；店名点了回地图开这家店。
  - 编辑性格：改标签选互斥的一个会取消另一个，满 10 个再选提示；改名字和口头禅保存后时间线里的名字跟着变；有改动时关面板先确认。
- CMP-C11（test:native-panels 覆盖快照和白名单；Swift 未编译，真机待验证）iOS 原生小伙伴页的一天。
  - 没起名时显示起名卡片，点“起名”收起主页并在网页小伙伴页弹出起名面板；起名后回到主页再进小伙伴页能看到时间线。
  - 翻日期、切筛选、“编辑”跳到网页编辑面板；开关在最下面。
- CMP-C12（test:companion 覆盖熟悉程度和检查状态；页面待在浏览器验证）别人的小伙伴（网页）。
  - 没登录打开 `/users/<id>/room`：「登录后才能看别人的小伙伴」和登录按钮。对方没起名、只有自己可见、关了小伙伴、被封禁、互相屏蔽：都是「没有找到这个小伙伴」。
  - 能看时：大头照、名字、「主人名 的小伙伴」（点了进主人主页）、标签和小习惯；互动过才有「你们是……」；没有饱食度和编辑。
  - 右上角「举报」打开预填的举报表；「屏蔽这位住民」先确认，确认后退出这一页，再打开对方主页已是屏蔽状态。
  - 时间线里点对方剧情里第三只的头像进它的小伙伴页；点自己的头像回到自己的小伙伴页。
- CMP-C13（test:companion、test:native-panels 覆盖列表规则；页面待在浏览器验证）自己的小伙伴页的熟悉的小伙伴、口味像你的小伙伴、检查提示。
  - 熟悉的小伙伴只列点头之交以上、最多 3 只，写着熟悉程度；口味像你的小伙伴最多 5 只，写着「主人名 的小伙伴」；没有人时整块不显示。
  - 名字没通过检查时名字下方提示「名字没通过检查，别人看到的是“饭桶”」，点了进编辑；编辑页名字旁和对应口头禅旁标出状态。
  - 别人的住民主页在对方小伙伴对你可见时有「去看 Ta 的小伙伴」。
- CMP-C14（test:native-panels 覆盖快照和白名单；Swift 未编译，真机待验证）iOS 原生的别人的小伙伴。
  - 别人主页的「去看 Ta 的小伙伴」、时间线头像、熟悉的小伙伴、口味像你的小伙伴都推入原生的别人的小伙伴页；侧滑返回回到上一页。
  - 点「主人名 的小伙伴」：从对方主页进来的直接返回，否则推入对方主页。
  - 右上角菜单「举报」收起主页后在地图上打开举报表；「屏蔽这位住民」确认后退回上一页，不打开举报。
  - 组标题带店名时点了回地图开这家店。
