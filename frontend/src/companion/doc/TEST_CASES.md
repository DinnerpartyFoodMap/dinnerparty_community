# 角色观察屋文字案例

遵循 [执行协议](../../../doc/TESTING.md)。规则和状态机由 `npm run test:companion` 覆盖。实际动画可以在预览页看（见 [README](README.md#预览)），下列各项还要在手机上看。

- CMP-C01（test:companion + 预览页；真机待验证，2026-11-20）底栏状态。
  - 首次进地图时小伙伴从上方落下并压扁，之后发呆、游走，走路时朝前进方向转头，不走到右侧按钮底下。
  - 等几轮会爬到右侧按钮组顶上站在中间，待一会儿后蹲下往左跳回地面。
  - 打开地点卡片再关掉，小伙伴从原处继续。
- CMP-C02（test:companion；真机待验证）睡觉与醒来。
  - 白天放着不动 150 秒，就地睡下，头顶冒 z。在按钮上也能睡。
  - 碰一下屏幕或拖动地图时眨眼、甩头、轻蹦一下醒来。iOS 原生底图上只拖地图也算操作。
  - 夜里（23:00–7:00）30 秒没操作就睡。
- CMP-C03（test:companion + 后端 tests/places/test_check_ins.js；真机待验证）饿与饱。
  - 48 小时没打卡（从没打过卡的账号从注册算）时，发呆耷拉着头、左右张望、肚子叫时抖一下，走得慢，不爬按钮。
  - 打卡后回到地图，补一次点头、爱心和蹦两下的庆祝，然后晃着笑；同一次打卡不会重复庆祝。
- CMP-C04（test:companion；真机待验证）与飞行的配合。
  - 小伙伴在按钮顶上或爬到一半时上拉更多功能，它先飞回地面范围上方悬停，不和随抽屉上移的按钮重叠。收起后落回地面。
  - 睡着时上拉更多功能，先醒再飞。
  - 展开搜索时，站在按钮上的小伙伴掉下来。
- CMP-C05（预览页 ?check，2026-11-20 已验证 84 个第三方模型；真机待验证）额外角色。
  - 资源包里的角色没有这些动作组时，用内置动作补上，各状态都会动。
  - 角色自带同名组时用角色自己的。
  - 眼睛参数名不同的模型睡觉时两眼都闭上。
- CMP-C06（真机待验证）打开「减弱动态效果」后小伙伴不走、不爬、不睡；上拉更多功能时淡出，再在上方淡入。
- CMP-C07（真机待验证，2026-11-20）未登录不显示小伙伴。退出登录回到地图，底栏和右侧按钮上都没有小伙伴；重新登录后从上方落下。
- CMP-C08（test:native-panels 覆盖视图模型与白名单；Swift 未编译，真机待验证）iOS 原生角色观察屋。
  - 「我的主页」点「角色观察屋」：主页不收起，观察屋从右侧推入并占满全屏，左边缘右滑途中能看到下面的主页，松手回到主页。
  - 关闭「开启角色观察屋」后房间与角色选择消失，地图底栏也不再有小伙伴；再打开恢复。保存失败时开关弹回并提示。
  - 内置角色显示静态预览；有额外角色时可切换，切到额外角色显示图标，地图底栏换成对应角色。
  - 观察屋开着时在别处打卡投喂成功，饱食度变化并冒一颗爱心。
